prime_tool

Module bigint 

Source
Expand description

Arbitrary-precision primality testing and factorization.

The rest of the library works on u64. This module handles inputs of any size, delegating to the fast u64 routines whenever a value fits.

  • Below DETERMINISTIC_BOUND (~3.3 × 10²⁴) primality is proven, using Miller-Rabin with the first 13 prime bases (Sorenson & Webster, 2015).
  • Above it, Baillie-PSW (Miller-Rabin base 2 + strong Lucas) is used. No counterexample is known, but the result is a probable prime.
  • Factorization uses trial division, perfect-power detection and Pollard-Brent rho, with an optional deadline because factoring large semiprimes can take arbitrarily long.
