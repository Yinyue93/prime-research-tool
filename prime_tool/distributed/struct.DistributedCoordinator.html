Expand description

Distributed coordinator for managing work across nodes.

Cloning is cheap and yields a handle to the same shared state.

pub async fn distribute_sieve( &self, range: Range<u64>, chunk_size: u64, ) -> Result<Vec<u64>>

Distribute prime sieving across the registered nodes.

The range is split into chunk_size work units. Each registered node is run as a local worker task that pulls work from the queue, executes it with LocalExecutor on a blocking thread and submits the result. Returns the sorted primes, or an error if no nodes are registered or the work does not finish within the completion timeout.
